# PROJECT PBO KHANIF

Aplikasi terminal (CLI) manajemen perpustakaan menggunakan Dart.

Fitur yang diterapkan: class/object, encapsulation dengan getter-setter dan validasi, inheritance (`Item` → `Buku`/`Majalah`), polymorphism, collection dan higher-order function (`where`, `fold`, `sort`), custom exception, serta async/await pada simulasi penyimpanan.

Jalankan dari folder proyek:

```powershell
dart run lib/main.dart
```
